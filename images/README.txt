Εδώ μπαίνουν οι εικόνες του site.

Ονόματα που ήδη χρησιμοποιούν οι σελίδες (βάλε τα αρχεία με ΑΚΡΙΒΩΣ αυτά τα ονόματα):
  SeminarOnArtemis.png  — η αφίσα του σεμιναρίου (σελίδες Άρτεμης)
  theodoni.jpg          — φωτογραφία της ιδρύτριας (σελίδα Σχετικά / About)
  favicon.png           — το εικονιδιάκι στην καρτέλα του browser (π.χ. 64x64)

Αν λείπει μια εικόνα, η σελίδα απλώς δεν τη δείχνει (δεν "σπάει").

Πού θα τις βρεις: στο WordPress → Πολυμέσα (Media) → άνοιξε την εικόνα → Λήψη.
Συμβουλή: κράτα τα ονόματα χωρίς κενά και ελληνικά (π.χ. seminario-anoia.jpg).
